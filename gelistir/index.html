Programı aç Tüm istekler

Programda neyi değiştirelim?

Kendi cümlelerinizle yazın. Claude genellikle birkaç dakika içinde programa ekler ve isteğinizin altına deneme linki yazar. Claude hesabı gerekmez.

1

Neyi, nerede istediğinizi yazın; mümkünse olması gereken cümleyi de ekleyin. T.C. kimlik no, işçi ya da işveren adı yazmayın — istekler herkese açıktır.

2Hangi bölümle ilgili? (isteğe bağlı)
3Gönderin
  1. GitHub sayfası isteğiniz yazılmış olarak açılır (ilk seferde GitHub hesabınızla giriş yapmanız istenir).
  2. Belge ya da ekran görüntüsü eklemek isterseniz o sayfadaki alt kutuya sürükleyin.
  3. En alttaki yeşil Create düğmesine basın. Cevap gelince GitHub size e-posta gönderir.
  4. Cevaptaki deneme linkinden deneyin; uygunsa altına Onaylıyorum yazın, program herkes için güncellenir.

Bir istek nasıl yayına girer?

İsteği yazın

Yukarıdaki kutuya yazıp gönderin, gerekirse belge ekleyin.

Claude işler

Gönderdiğiniz anda başlar; programı değiştirir ve otomatik testleri çalıştırır. Gerekirse önce soru sorar.

Deneyin

İsteğinizin altına yazılan deneme linkinden deneyin. Gerçek verileriniz etkilenmez. Düzeltme gerekiyorsa yorum yazın.

Siz onaylayın

Uygunsa isteğinizin altına Onaylıyorum yazın.

Herkes için yayında

Onayınızdan birkaç dakika sonra program herkes için güncellenir, istek kapanır.

İlk kez mi kullanıyorsunuz? (bir kerelik)

  1. github.com’dan ücretsiz bir hesap açın.
  2. Kullanıcı adınızı yöneticiye iletin.
  3. E-postanıza gelen depo davetini kabul edin. Yalnızca davetli kişilerin istekleri işlenir.
